# Biolytica website — multi-page edition

The website is now organised into separate pages rather than one long scrolling page. `index.html` is the cover/home page and each menu opens its own HTML page.

## Pages
- `index.html` — cover page and section directory
- `about.html`, `events.html`, `team.html`
- `timetable.html`, `syllabus.html`, `pyq.html`, `resources.html`
- `gallery.html`, `notices.html`, `join.html`, `admin.html`

## Publish on GitHub Pages
Upload all files and folders in this package to the repository root, preserving the `assets/` folder. Commit to the configured branch.

## Admin upload
The admin uploader uses the GitHub Contents API from the browser. An administrator must provide a repository-scoped fine-grained token with Contents read/write permission. Never embed a token in source code. For stronger security, a server-side upload service is preferable.

## Content note
Team portraits are crops from screenshots supplied by the site owner. Replace with original high-resolution photographs when available. PYQ year categories are provided, but actual question-paper files must be uploaded by the society.
